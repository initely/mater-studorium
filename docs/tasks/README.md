# Задачи для исполнителя

Как пользоваться:
1. Бери задачи строго по порядку ID. Не начинай задачу, пока её зависимости не закрыты (CI зелёный, критерии приёмки выполнены).
2. Каждая задача рассчитана на одну сессию работы модели. Если задача не влезает, остановись, предложи разбиение и не делай половину.
3. Перед стартом прочитай `CLAUDE.md` и разделы ТЗ, указанные во «Входах».
4. В конце задачи:
   - `flutter analyze` без замечаний, `dart format` применён, `flutter test` зелёный;
   - отметь задачу ✅ в таблице ниже;
   - если по ходу принято решение, которого нет в ТЗ, допиши его в §14 [ТЗ](../TZ.md).
5. Нашёл противоречие в ТЗ — спроси, не угадывай.

**Почему такая модель.** Opus берёт задачи, где ошибка дорогая и плохо ловится тестами: контракты данных, промпты, синхронизация, планировщик, безопасность. Sonnet берёт хорошо специфицированные задачи с понятными тестами: UI, CRUD, обвязку.
